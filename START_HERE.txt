EMAIL OTP
---------
Gmail is OPTIONAL for local development. If Gmail is not configured,
the registration OTP appears only in the black Nova server window.
To send real email OTP, run CONFIGURE_GMAIL_OTP.bat once, enter your Gmail
and Gmail App Password, then restart START_NOVA_STORE.bat.

REGISTERING A NEW ACCOUNT
-------------------------
- If Gmail SMTP variables are configured, the OTP is sent by email.
- If Gmail is NOT configured, the real backend prints the 6-digit OTP in
  the black Nova server window. Enter that code on the website.
- After verification, the account is saved permanently in users.json.

DATA FILES USED BY THE SERVER
-----------------------------
users.json     = users + passwords hashes + wallet balances
admins.json    = admin login data
products.json  = products and stock
carts.json     = saved carts

Always edit/use the JSON files inside the same extracted folder as
api_server.py. The backend reads those exact files.
